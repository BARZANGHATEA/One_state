# ربات تلگرام OneState 🎃

هر روز برای همه‌ی اکانت‌ها این کارها را انجام می‌دهد:

1. **Daily Rewards:** جایزه‌ی روز بعدیِ هر اکانت را خودش پیدا و کلیم می‌کند (روز ۱۰ یک اکانت، روز ۲۶ اکانت دیگر).
2. **EVENT TASKS:** تسک‌های «Visit our website» و «Claim a reward in the rewards calendar» را کلیم می‌کند.
3. **EVENT STORE:** آخرین آیتم با اسم `1` را می‌خرد (روزی فقط یک بار).

بعد گزارش هر اکانت را در تلگرام برایتان می‌فرستد.

## چطور کار می‌کند

همه‌چیز روی **Vercel (پلن رایگان)** اجرا می‌شود و به GitHub Actions نیازی نیست:

| بخش | کارش |
|---|---|
| `api/telegram.js` | ربات تلگرام و دستورها |
| `api/run.js` | باز کردن سایت در یک Chrome سرورلس و انجام کارها؛ هر بار یک مرحله از یک اکانت، بعد مرحله‌ی بعد را خودش شروع می‌کند |
| `api/cron.js` | اجرای خودکار روزانه |
| خود تلگرام | ذخیره‌ی اطلاعات: یک فایل رمزنگاری‌شده که در چت ربات پین می‌شود |
| `login.bat` | لاگین یک‌باره روی کامپیوتر شما |

هیچ اطلاعاتی روی Vercel یا GitHub ذخیره نمی‌شود. سشن‌ها با `SESSION_KEY` رمزنگاری شده‌اند.

**چرا لاگین روی کامپیوتر است؟** گوگل و دیسکورد اجازه نمی‌دهند ربات خودش با آن‌ها لاگین کند. برای همین یک بار خودتان در Chrome لاگین می‌کنید و `login.bat` فقط سشن OneState را برای ربات می‌فرستد. رمز اکانت‌ها جایی ذخیره نمی‌شود.

## نصب (یک بار)

### ۱. ساخت ربات
1. در تلگرام به `@BotFather` بروید، `/newbot` بزنید و **توکن** را بردارید → `BOT_TOKEN`
2. آیدی عددی خودتان را از `@userinfobot` بگیرید → `ADMIN_ID`
3. یک رمز طولانی بسازید → `SESSION_KEY`. این رمز باید در Vercel و کامپیوتر **دقیقاً یکی** باشد.
4. دو رمز دیگر فقط با حروف انگلیسی، عدد، `_` و `-` بسازید → `WEBHOOK_SECRET` و `CRON_SECRET`

### ۲. ورسل
1. در vercel.com روی **Add New → Project** بزنید و این ریپازیتوری را Import کنید.
2. در **Settings → Environment Variables** این‌ها را برای **Production** بگذارید:
   `BOT_TOKEN`، `ADMIN_ID`، `SESSION_KEY`، `WEBHOOK_SECRET`، `CRON_SECRET`
3. Deploy (یا Redeploy) کنید و بعد این آدرس را یک بار باز کنید:
   `https://آدرس-پروژه.vercel.app/api/setup?key=WEBHOOK_SECRET`
   باید پیام `Webhook set` را ببینید.
4. در تلگرام به ربات `/start` بدهید.

### ۳. اضافه کردن اکانت‌ها (روی ویندوز)
1. Node.js نسخه‌ی LTS را از nodejs.org نصب کنید.
2. فایل `.env.example` را کپی کنید، اسمش را `.env` بگذارید و `BOT_TOKEN`، `ADMIN_ID` و `SESSION_KEY` را در آن پر کنید.
3. روی `login.bat` دوبار کلیک کنید و یک اسم بدهید (مثلاً `acc1`).
4. یک پنجره‌ی Chrome باز می‌شود. با همان اکانت در سایت لاگین کنید، بعد در پنجره‌ی سیاه Enter بزنید.
5. همین کار را برای `acc2`، `acc3` و `acc4` تکرار کنید.

### ۴. تست
در تلگرام `/debug` بزنید. برای هر اکانت اسکرین‌شات هر مرحله و یک گزارش می‌آید.

## استفاده‌ی روزانه
- ربات هر روز حدود ساعت **۰۴:۰۰ تهران** خودکار اجرا می‌شود (کمی بعد از ریست سایت). اگر یک روز دستی هم `/run` بزنید، آیتم دوباره خریده نمی‌شود.
- دستورها:
  - `/accounts` لیست اکانت‌ها و نتیجه‌ی آخرین اجرا
  - `/run` اجرای همین الان
  - `/run acc2` اجرا فقط برای یک اکانت
  - `/debug` اجرا با اسکرین‌شات
  - `/remove acc2` حذف یک اکانت
- اگر گزارش گفت **سشن منقضی شده**، فقط `login.bat` را برای همان اسم دوباره اجرا کنید. چون پروفایل Chrome ذخیره شده، معمولاً لاگین هنوز هست و فقط Enter می‌زنید.

## وقتی ایونت عوض شد
آدرس ایونت الان `/events/halloween/...` است. وقتی ایونت بعدی شروع شد، در Vercel یک Environment Variable به اسم `EVENT_SLUG` با اسم ایونت جدید بسازید و Redeploy کنید.
اگر آیتم روزانه اسم دیگری داشت، `ITEM_NAME` را هم به همین شکل اضافه کنید.

## نکته‌ها
- فایل پین‌شده در چت ربات **اطلاعات ربات است**؛ آن را حذف یا آنپین نکنید. اگر نمی‌خواهید در چت باشد، یک کانال خصوصی بسازید، ربات را ادمین کنید و آیدی کانال را در `STORE_CHAT_ID` (در Vercel و `.env`) بگذارید.
- اگر سایت ورود از سرورهای Vercel را قبول نکرد، می‌توانید همین کار را روی کامپیوتر با `run-local.bat` و Task Scheduler ویندوز اجرا کنید.
- اتوماسیون و داشتن چند اکانت ممکن است خلاف قوانین OneState باشد. مسئولیت استفاده با خودتان است.
