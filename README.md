# ربات تلگرام OneState 🎃

هر روز برای همه‌ی اکانت‌ها این کارها را انجام می‌دهد:

1. **Daily Rewards:** جایزه‌ی روز بعدیِ هر اکانت را خودش پیدا و کلیم می‌کند (روز ۱۰ یک اکانت، روز ۲۶ اکانت دیگر).
2. **EVENT TASKS:** تسک‌های «Visit our website» و «Claim a reward in the rewards calendar» را کلیم می‌کند.
3. **EVENT STORE:** آخرین آیتم با اسم `1` را می‌خرد (روزی فقط یک بار).

بعد گزارش هر اکانت را در تلگرام برایتان می‌فرستد.

## چطور کار می‌کند

| بخش | کجا اجرا می‌شود | کارش |
|---|---|---|
| ربات تلگرام | Vercel (سرورلس) | دستورها، ذخیره‌ی سشن‌ها، شروع اجرای روزانه |
| مرورگر خودکار | GitHub Actions (رایگان) | باز کردن سایت و کلیک‌ها |
| ذخیره‌ی اطلاعات | خود تلگرام | یک فایل رمزنگاری‌شده که در چت ربات پین می‌شود |
| لاگین یک‌باره | کامپیوتر شما | `login.bat` |

هیچ اطلاعاتی روی Vercel یا GitHub ذخیره نمی‌شود. سشن‌ها با `SESSION_KEY` رمزنگاری شده‌اند.

**چرا لاگین روی کامپیوتر است؟** گوگل و دیسکورد اجازه نمی‌دهند ربات خودش با آن‌ها لاگین کند. برای همین یک بار خودتان در Chrome لاگین می‌کنید و `login.bat` فقط سشن OneState را برای ربات می‌فرستد. رمز اکانت‌ها جایی ذخیره نمی‌شود.

## نصب (یک بار)

### ۱. ساخت ربات
1. در تلگرام به `@BotFather` بروید، `/newbot` بزنید و **توکن** را بردارید → `BOT_TOKEN`
2. آیدی عددی خودتان را از `@userinfobot` بگیرید → `ADMIN_ID`
3. یک رمز طولانی تصادفی بسازید → `SESSION_KEY`. این رمز باید در هر سه جا (Vercel، GitHub، کامپیوتر) **دقیقاً یکی** باشد.
4. دو رمز دیگر فقط با حروف انگلیسی و عدد بسازید → `WEBHOOK_SECRET` و `CRON_SECRET`

### ۲. گیت‌هاب
1. یک ریپازیتوری **Private** بسازید (مثلاً `onestate-bot`) و همه‌ی فایل‌های این پوشه را آپلود کنید.
2. **Settings → Secrets and variables → Actions → New repository secret** و این سه را اضافه کنید:
   `BOT_TOKEN`، `ADMIN_ID`، `SESSION_KEY`
3. یک توکن بسازید: **Settings (حساب خودتان) → Developer settings → Fine-grained tokens → Generate**
   - Repository access: فقط همین ریپازیتوری
   - Permissions → **Actions: Read and write**
   - توکن ساخته‌شده → `GH_TOKEN`

### ۳. ورسل
1. در vercel.com روی **Add New → Project** بزنید و همین ریپازیتوری را Import کنید.
2. در **Environment Variables** این‌ها را بگذارید:
   `BOT_TOKEN`، `ADMIN_ID`، `SESSION_KEY`، `WEBHOOK_SECRET`، `CRON_SECRET`، `GH_TOKEN`،
   و `GH_REPO` به شکل `نام‌کاربری‌گیت‌هاب/onestate-bot`
3. Deploy کنید و بعد این آدرس را یک بار در مرورگر باز کنید:
   `https://آدرس-پروژه.vercel.app/api/setup?key=WEBHOOK_SECRET`
   باید پیام `Webhook set` را ببینید.
4. در تلگرام به ربات `/start` بدهید.

### ۴. اضافه کردن اکانت‌ها (روی ویندوز)
1. Node.js نسخه‌ی LTS را از nodejs.org نصب کنید.
2. فایل `.env.example` را کپی کنید، اسمش را `.env` بگذارید و `BOT_TOKEN`، `ADMIN_ID` و `SESSION_KEY` را در آن پر کنید.
3. روی `login.bat` دوبار کلیک کنید و یک اسم بدهید (مثلاً `acc1`).
4. یک پنجره‌ی Chrome باز می‌شود. با همان اکانت در سایت لاگین کنید، بعد در پنجره‌ی سیاه Enter بزنید.
5. همین کار را برای `acc2`، `acc3` و `acc4` تکرار کنید. هر اکانت پروفایل Chrome جدای خودش را دارد.

### ۵. تست
در تلگرام `/debug` بزنید. بعد از ۳–۵ دقیقه گزارش هر اکانت را با اسکرین‌شات هر مرحله می‌گیرید.

## استفاده‌ی روزانه
- ربات هر روز حدود ساعت **۰۳:۵۰ تهران** خودکار اجرا می‌شود (کمی بعد از ریست سایت)، و یک بار دیگر حدود **۱۰:۱۰** برای اطمینان. اجرای دوم چیزی را دوباره نمی‌خرد.
- دستورها:
  - `/accounts` لیست اکانت‌ها و نتیجه‌ی آخرین اجرا
  - `/run` اجرای همین الان
  - `/run acc2` اجرا فقط برای یک اکانت
  - `/debug` اجرا با اسکرین‌شات
  - `/remove acc2` حذف یک اکانت
- اگر گزارش گفت **سشن منقضی شده**، فقط `login.bat` را برای همان اسم دوباره اجرا کنید. چون پروفایل Chrome ذخیره شده، معمولاً لاگین هنوز هست و فقط Enter می‌زنید.

## وقتی ایونت عوض شد
آدرس ایونت الان `/events/halloween/...` است. وقتی ایونت بعدی شروع شد، در گیت‌هاب بروید به
**Settings → Secrets and variables → Actions → Variables** و `EVENT_SLUG` را به اسم ایونت جدید تغییر دهید.
اگر آیتم روزانه اسم دیگری داشت، `ITEM_NAME` را هم تغییر دهید.

## نکته‌ها
- فایل پین‌شده در چت ربات **اطلاعات ربات است**؛ آن را حذف یا آنپین نکنید. اگر نمی‌خواهید در چت باشد، یک کانال خصوصی بسازید، ربات را ادمین کنید و آیدی کانال را در `STORE_CHAT_ID` (در Vercel، GitHub و `.env`) بگذارید.
- اگر سایت ورود از سرورهای گیت‌هاب را قبول نکرد، می‌توانید همین کار را روی کامپیوتر با `run-local.bat` و Task Scheduler ویندوز اجرا کنید.
- اتوماسیون و داشتن چند اکانت ممکن است خلاف قوانین OneState باشد. مسئولیت استفاده با خودتان است.
